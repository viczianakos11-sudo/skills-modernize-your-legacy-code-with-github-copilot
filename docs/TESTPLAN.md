# COBOL Account Management System Test Plan

This plan covers the current menu, account operations, and in-memory balance behavior. For isolated cases, start a fresh process so the balance begins at `1000.00`. For multi-step cases, keep the same process running. Amounts use the COBOL field `PIC 9(6)V99`, which represents up to six integer digits and two decimal digits.

For cases marked as characterization or stakeholder decision, record what the current executable does; do not treat an unspecified input behavior as an agreed business requirement. Leave Actual Result and Status open until the case is run and reviewed.
